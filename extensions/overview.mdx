GSD 2 includes a powerful extension system that ships with 13 production-ready extensions and 3 specialized subagents. All extensions are loaded automatically—no configuration required.

## Extension Architecture

Extensions live in `~/.gsd/agent/` and are synced from the npm package on every launch. This means:

- **npm updates take effect immediately** — no manual reinstall needed
- **Extensions are versioned** — extensions update with GSD updates
- **Always-overwrite sync** — bundled extensions can't drift out of date

<Note>
Extensions are TypeScript modules that hook into the Pi SDK's agent lifecycle, providing tools, commands, and event handlers.
</Note>

## Extension Lifecycle

Extensions hook into key lifecycle events:

```typescript
pi.on("session_start", async (event, ctx) => { /* ... */ });
pi.on("before_agent_start", async (event, ctx) => { /* ... */ });
pi.on("session_compact", async () => { /* ... */ });
pi.on("session_shutdown", async () => { /* ... */ });
```

<AccordionGroup>
  <Accordion title="session_start">
    Runs once when a new GSD session starts. Used for:
    - Loading saved state from disk
    - Discovering surviving processes from previous sessions
    - Initializing session-scoped resources
  </Accordion>
  
  <Accordion title="before_agent_start">
    Runs before each agent turn. Used for:
    - Injecting context (e.g., background process alerts, GSD state)
    - Loading system prompts dynamically
    - Surfacing environment changes
  </Accordion>
  
  <Accordion title="session_compact">
    Runs when context is compacted (conversation history pruned). Used for:
    - Preserving critical state across compaction
    - Queueing alerts to re-inject lost context
  </Accordion>
  
  <Accordion title="session_shutdown">
    Runs when the session ends. Used for:
    - Cleanup (killing background processes, closing browsers)
    - Persisting state to disk
  </Accordion>
</AccordionGroup>

## Tool Registration

Extensions register tools via the Pi SDK:

```typescript
pi.registerTool({
  name: "tool_name",
  label: "Human Label",
  description: "What the tool does",
  promptGuidelines: [
    "When to use this tool",
    "Best practices for parameters",
  ],
  parameters: Type.Object({ /* ... */ }),
  async execute(toolCallId, params, signal, onUpdate, ctx) {
    // Implementation
  },
});
```

## Command Registration

Extensions can also register slash commands:

```typescript
pi.registerCommand("command-name", {
  description: "What the command does",
  handler: async (ctx) => {
    // Implementation
  },
});
```
